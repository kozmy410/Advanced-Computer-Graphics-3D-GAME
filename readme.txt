Game Mode Controls

    W / A / S / D: Movement (Walk)

    Mouse: Look / Rotate Camera

    C: Toggle Mouse Capture (Lock/Unlock Look)

    Mouse Wheel: Inventory Scroll

    F: Toggle Flashlight

    Q: Drop Selected Item

    1 - 0: Select Inventory Slot

    M: Toggle Minimap

    TAB: Switch to Editor Mode

Editor Mode Controls

    W / A / S / D: Fly Forward / Left / Back / Right

    Q / E: Descend / Ascend (Vertical Movement)

    Left Shift: Sprint (Increase Flight Speed)

    Left Alt: Unlock Cursor (Free Mouse for GUI)

    Right Click: Select Object (Raycasting) //May not work anymore

    G: Grab / Drop (Toggle Move Selected Object)

    1 / 2 / 3: Quick Spawn (Cube / Sphere / Light)

    CTRL + Z / Y: Undo / Redo Action

    K / L: Save / Load Level File (level_data.txt)
